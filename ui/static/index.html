A fair fight. Every box you tick below becomes one row of the results table, and each row re-runs your current config with only that one setting swapped. Everything else stays identical: the same seed means the same tasks arrive at the same moments, over the same links, with the same random noise. So if two rows differ in the results, the setting you changed is the only thing that could have caused it. Tick several seeds to check a result is not a fluke; you get a row per seed plus an average row per setting.
